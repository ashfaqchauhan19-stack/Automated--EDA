# 📊 Automated EDA Tool

### Turn a CSV file into meaningful insights — faster.

**Automated EDA Tool** is a Streamlit-based web application that makes Exploratory Data Analysis (EDA) simple and interactive.

Instead of manually checking every column, statistic, and chart, users can upload a CSV dataset and quickly explore its structure, data quality, patterns, and visual insights.

## ✨ What can it do?

* 📂 Upload CSV datasets
* 👀 Preview the dataset
* 📊 View rows, columns, missing values, and duplicate records
* 🔎 Get detailed column information
* 📈 Generate numerical statistics
* 📉 Explore numerical distributions
* 📦 Identify potential outliers using box plots
* 🔥 Analyze correlations with a heatmap
* 📊 Explore categorical variables
* 🤖 Generate AI-powered EDA insights using Groq

## 🛠️ Tech Stack

* Python
* Streamlit
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Groq API

## 🚀 How It Works

```text
Upload CSV
    ↓
Dataset Profiling
    ↓
Statistical Analysis
    ↓
Data Visualizations
    ↓
AI-Powered Insights
```

The goal is to make the first stage of data analysis faster, easier, and more accessible — especially when working with a new dataset.

## 💡 Why I Built This

Exploratory Data Analysis is an important first step in any data project, but it can also become repetitive.

I built this project to experiment with combining **Python, data visualization, Streamlit, and Generative AI** into one practical tool.

## 🔐 API Key Security

API keys are stored securely using environment variables locally and Streamlit Secrets when deployed.

API keys are **not stored in the GitHub repository**.
