# 🤖 Automated EDA Tool

An AI-powered Exploratory Data Analysis (EDA) web application built with Streamlit, Python, Pandas, and an LLM.

## 📌 Project Overview

The Automated EDA Tool allows users to upload a CSV dataset and automatically perform exploratory data analysis.

The application provides:

- Dataset preview
- Dataset dimensions
- Missing-value analysis
- Duplicate-row detection
- Data-type analysis
- Unique-value analysis
- Numerical summary statistics
- AI-generated EDA code
- Automatic visualizations
- AI-generated insights

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib
- Seaborn
- OpenAI API
- python-dotenv
